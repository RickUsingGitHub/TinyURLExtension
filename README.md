# TinyURL Shortener Chrome Extension

This Chrome extension shortens the current tab's URL using the TinyURL API.

## How to Install

1.  **Download the code:** Clone this repository or download it as a ZIP file and unzip it.
2.  **Open Chrome Extensions:** In Chrome, navigate to `chrome://extensions`.
3.  **Enable Developer Mode:** Turn on the "Developer mode" toggle in the top-right corner.
4.  **Load the extension:**
    *   Click the "Load unpacked" button.
    *   Select the directory where you saved the code.
5.  The extension is now installed!

## How to Use

1.  **Get a TinyURL API Key:** You'll need a free API key from the TinyURL website.
2.  **Save the API Key:**
    *   Click the extension icon in your toolbar.
    *   Paste your API key into the input field and click "Save".
3.  **Shorten a URL:**
    *   Go to the tab you want to shorten.
    *   Click the extension icon.
    *   Click "Shorten URL".
4.  The shortened URL will be displayed and copied to your clipboard.
